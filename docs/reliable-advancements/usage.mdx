Reliable Advancements enhances Minecraft's advancement system with an in-game editor, visual customization, and quality-of-life improvements!

## Features

- **In-game editor** — Create, edit, and delete advancements on the fly
- **Tab customization** — Rename tabs, change background textures, and configure randomized backgrounds
- **Visual overrides** — Per-advancement custom colors for icons, titles, and connection lines
- **UI improvements** — Zoom support, background blur, alphabetical tab sorting, and UI scaling
- **Criteria display** — Show which criteria you've earned or still need on partially-completed advancements
- **Discovery mode** — Hide advancement names and descriptions until unlocked
- **Reward claiming** — Optional mode requiring players to manually click to claim advancement rewards
- **Inventory button** — Configurable button on the inventory screen for quick access to advancements

## Getting Started

1. Install the mod on both the server and client
2. Open the advancements screen with **L** (default keybind)
3. To edit advancements, [enable edit mode](edit-mode) in the config (requires OP)

## Where Edits Are Saved

On singleplayer and LAN, edits are written by default to the mod's global config folder:

```
config/reliable_advancements_edits/
```

This means edits apply to every world and can be shipped directly in a modpack zip, no datapack loader needed. On dedicated servers, edits go to the world save folder instead. See [Saving Globally](saving-globally) for the full breakdown.
